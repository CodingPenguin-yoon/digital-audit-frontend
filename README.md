# Digital Audit frontend

React + Vite + Three.js로 구현한 데스크톱 감사 관제 프로토타입입니다. 중앙의 원형 3D 플랫폼에서 부서를 선택하면 부서별 지표, 신호 유형, 거래 예시가 함께 바뀝니다. 블랙·그래파이트 바탕에 샴페인 골드와 브라스 조명을 더한 관제 화면입니다.

## 실행

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 4173
```

## 검증과 빌드

```sh
npm run build
npm run test:sites
```

## Docker 실행

```sh
docker build -t digital-audit-frontend .
docker run --rm --name digital-audit-frontend -p 127.0.0.1:8080:80 digital-audit-frontend
```

Nginx에서 정적 파일을 제공하며 `/healthz`로 상태를 확인할 수 있습니다.

## 구현 범위

- 실제 WebGL 원형 플랫폼, 부서별 이상징후 높이, 조명과 그림자
- 드래그 회전, 부서 선택, 이전·다음, 자동 순환 및 일시정지
- 선택 부서의 지표와 거래 내역 연결, 거래 검색·위험도 필터·근거 확인
- 별도 `감사 도구` 탭: 데이터 업로드, 이상징후 탐지, 새 패턴 발견, 증빙 대조, 위변조 분석
- 키보드 부서 선택, 근거 창의 포커스 제어와 Escape 닫기, 동작 줄이기 설정 지원
- WebGL을 사용할 수 없는 경우 부서 버튼과 일반 지표로 점검 흐름 유지

화면은 데스크톱 웹 전용이며 최소 너비는 960px입니다. 거래와 분석 결과는 고정된 가상 예시입니다. 전체 지표는 6개 부서·2,280개 거래·29개 이상징후를 사용하고, 거래 표와 유형 분포는 별도로 표시한 소수의 예시만 보여줍니다. 파일 선택은 브라우저에서 파일명과 크기만 표시하며 파싱·서버 전송·실제 분석은 연결하지 않았습니다.

중앙 3D 무대에는 사용자가 제공한 TEAM 007 / GOLDFINGER 배경 이미지를 사용합니다. 바닥 표면에는 생성한 로컬 질감 이미지를 사용하며, 3D 모델·차트·레이블·인터페이스는 실제 코드로 렌더링합니다. 아이콘은 Phosphor, 폰트는 Google Fonts의 DM Sans와 Noto Sans KR을 사용합니다. 외부 폰트를 불러올 수 없으면 시스템 폰트로 표시됩니다.
