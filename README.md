# Digital Audit frontend

React + Vite + Three.js로 구현한 데스크톱 감사 검토 프로토타입입니다. 시나리오 × 부서 3D 맵에서 거래를 좁히고, 동일 거래의 탐지 이유·증빙 대조·위변조 신호를 한 화면에서 확인한 뒤 판정과 의견을 저장합니다. 인물 이미지 없이 검정·그래파이트와 골드 색상을 사용하고 신호가 있는 막대는 빨강으로 표시합니다.

## 실행

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 4173
```

## 검증과 빌드

```sh
npm run build
npm run test:sites
node --test tests/audit-data.test.mjs tests/audit-request.test.mjs tests/review-data.test.mjs
```

## Docker 실행

```sh
docker build -t digital-audit-frontend .
docker run --rm --name digital-audit-frontend -p 127.0.0.1:8080:80 digital-audit-frontend
```

Nginx에서 정적 파일을 제공하며 `/healthz`로 상태를 확인할 수 있습니다.

## 구현 범위

- 감사 담당자 / 관리자 시연 역할 선택과 역할별 할 일
- 실제 WebGL 맵: X 시나리오, Y 부서 상위 최대 8개, Z 거래 건수. 셀 클릭과 방향키·Enter 선택, 드래그·자동 회전
- 같은 날짜·점검 유형·거래 예시로 맵 건수와 거래 목록을 연결하고 판정 상태별로 목록 필터
- 거래 상세에 탐지 이유·증빙 대조·위변조 신호 통합, 위반·정상·보류와 필수 검토 의견 저장
- 담당자의 패턴 등록 요청, 관리자의 등록·기각과 재검토, 관련 거래 연결
- 자연어 요청의 기간·부서·시나리오 미리보기 후 적용. 제외·부정·금액 등 미지원 조건은 안내
- 별도 `감사 도구` 탭: 거래 검토, 패턴 검토, 자료 업로드
- 검토 창의 포커스 제어와 Escape 닫기, 동작 줄이기 설정, WebGL 미지원 시 선택 가능한 표 제공

화면은 데스크톱 웹 전용이며 최소 너비는 960px입니다. 거래와 분석 결과는 고정된 가상 예시입니다. 상단 원본 집계 예시는 6개 부서·2,280개 거래·29개 이상징후입니다. 3D 맵·점검 유형·검토 목록은 같은 16개 거래 예시 중 이상징후가 있는 8건을 기준으로 동작합니다. 새 패턴 예시는 규정 신호와 겹칠 수 있어 유형별 수의 합은 고유 거래 수와 다릅니다. 파일 선택은 브라우저에서 파일명과 크기만 표시하며 파싱·서버 전송·실제 분석은 연결하지 않았습니다.

중앙 3D 무대는 인물 이미지 없이 검정·그래파이트 배경으로 표시합니다. 3D 모델·차트·레이블·인터페이스는 실제 코드로 렌더링합니다. 아이콘은 Phosphor, 폰트는 Google Fonts의 DM Sans와 Noto Sans KR을 사용합니다. 외부 폰트를 불러올 수 없으면 시스템 폰트로 표시됩니다.

역할 전환은 화면 시연용이며 실제 로그인·권한 검증은 연결하지 않았습니다. 판정과 패턴 결정은 이 브라우저의 localStorage에 저장됩니다. 등록된 패턴은 시제품 상태만 바꾸며 실제 탐지 기준에 적용하지 않습니다. 자연어 요청은 지원하는 표현에서 예시 필터를 해석하며 LLM을 호출하지 않습니다.
